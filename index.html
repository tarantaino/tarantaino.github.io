First Level Master's thesis

Docker and Podman: a comparative vulnerability analysis

Master's thesis, written in LaTeX, First-Level Master in Cybersecurity

The thesis explores the isolation mechanisms and intrinsic vulnerabilities of Docker and Podman. Through a methodical, comparative study of historical CVEs (Common Vulnerabilities and Exposures), the research shows how a software's architectural design shapes not only its functionality but also the offensive strategies of attackers.

Projects

Honeytrap

Python, Paramiko, Flask, SQLite, JavaScript, Claude, Docker

An SSH honeypot: a fake server that rejects every login and records the IP, username and password of brute-force attempts. Events are stored in SQLite and shown in real time on a Flask web dashboard. The honeypot and the dashboard are two separate services running in Docker containers.

Security measures included: parameterized queries against SQL injection, protection against stored XSS in the dashboard, containers running as a non-root user, and a dashboard reachable from localhost only.
